# SPLIT INTO REQUIRED / OPTIONAL ON 2026-07-25.
# `pycspr==1.2.0` used to be a hard requirement on the line below, which meant
# `pip install -r requirements.txt` failed for anyone without a Rust toolchain:
# pycspr 1.2.0 pins blake3<0.5.0, and the only blake3 in that range (0.4.1) ships
# as a source sdist with no prebuilt wheel for Python 3.12+, so the install dies
# at `metadata-generation-failed`. That is an upstream pycspr constraint, not a
# bug here — but it was blocking the part most people actually want to run:
#
#   • casper_defi_agent.py   — the autonomous-agent demo. Imports only requests
#     and dotenv. Verified 2026-07-25: runs against the live oracle and prints
#     its execute/block decisions. Does NOT need pycspr.
#   • casper_oracle_pusher.py — the on-chain pusher. Needs pycspr, but already
#     guards the import (try: import pycspr / except ImportError: PYCSPR_OK=False),
#     so without it the module still loads and reports the missing dependency
#     instead of crashing.
#
# Install the two lines below and the demo runs. Add pycspr only if you want the
# Python pusher to sign and send real deploys.
# ─────────────────────────────────────────────────────────────────────────────

python-dotenv>=1.2.2
